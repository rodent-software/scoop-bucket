# rodent-software Scoop bucket

Scoop manifests for [rodent-software](https://github.com/rodent-software) tools.

## Usage

```powershell
scoop bucket add rodent-software https://github.com/rodent-software/scoop-bucket
scoop install packrat
```

## Manifests

| App | Manifest |
| --- | --- |
| [packrat](https://github.com/rodent-software/packrat) | [`bucket/packrat.json`](bucket/packrat.json) |

`packrat` needs `libdvdcss` at runtime to read CSS-encrypted discs; see the
[installation guide](https://github.com/rodent-software/packrat/blob/main/docs/installation.md).
